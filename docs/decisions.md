## 2026-11-20 채널 추천(기획안), 프롬프트는 화면에서

  - 실행: 추천 탭의 "지금 추천 받기"(Actions `ideas`), 또는 자동 추천(매일 03:17 KST 실행의 `ideas-daily`, 채널 설정에서 켜고 주기 1~7일, **기본 꺼짐**).

## 2026-11-20 영상 길이 20~55초 가변, 1분 넘으면 막기

- 결정: 에피소드마다 영상 길이(20~55초, 5초 단위)를 고른다. 채널마다 기본 길이(라쿤씨 30초)가 있다.
  - 길이에서 장면 수(약 8.5초에 하나, 최소 4개)와 AI 영상 장면 수(절반까지, 최대 3개), 내레이션 글자 수가 나온다(`lengthRules`).
  - 내레이션 글자 수는 실측한 읽는 속도 **공백 제외 4.4자/초**로 정한다.
    2026-11 프로덕션 실측에서 기존 규칙(20초 목표, 150~170자)으로 만든 영상이 **37.2초**였다(160자, ElevenLabs v3).
  - 1분 차단 세 곳: 대본(1분을 넘길 글자 수면 오류) · 합성(내레이션 실제 길이로 영상이 59.5초를 넘으면 합성하지 않음) · 업로드(59.5초 넘는 완성 영상은 올리지 않음).
  - 기존 에피소드는 35초로 둔다(지금까지 대본 규칙이 실제로 만든 길이).
- 이유: 사용자 요청(20초~1분, 절대 1분을 넘지 않게). 영상 길이는 내레이션 길이로 정해지므로 글자 수 기준을 실측 속도에 맞춘다.
- 검토한 대안: 장면 수를 길이/5초로(장면이 많아 크레딧이 크게 늚, 실제 장면 길이는 내레이션에 맞춰 늘어나므로 의미 없음).
- 영향: `episodes.target_seconds`(기존 35), `channels.default_seconds`(30). 시스템 프롬프트에서 분량 숫자를 빼고 사용자 메시지의 "분량"으로 넘긴다.
  목소리마다 속도가 다르면 4.4자/초를 다시 잰다(합성 결과의 `meta.seconds` 와 내레이션 글자 수).

- 결정: 에피소드를 유튜브 채널 단위로 나눈다. 상단 메뉴는 채널마다 탭 하나(🦝 피부건강 라쿤씨 · 🐦 새새 열매) + 클립 보관함 + 설정.
  - 채널마다 기본 제작 방식을 정한다: **생성형**(= 기존 "주제로 만들기", 대본 → AI 장면) · **편집형**(= 기존 "영상 먼저 찾기", 무료 영상 → 스토리).
    에피소드마다 다른 방식도 고를 수 있다.
  - 유튜브 리프레시 토큰은 채널마다 따로 GitHub Secret 에 둔다(라쿤씨 `YOUTUBE_REFRESH_TOKEN` 그대로, 새새 열매 `YOUTUBE_REFRESH_TOKEN_SAESAE`).
    클라이언트 ID·보안 비밀은 공통.
  - 올릴 유튜브 채널 ID 는 GitHub 변수(`YOUTUBE_CHANNEL_ID`, 2026-11-19 #42) 대신 대시보드 채널 설정에 둔다.
    채널이 여럿이라 **채널 ID 가 없으면 자동 업로드를 하지 않는다**(토큰의 채널과 다르면 올리지 않는 확인은 그대로).
- 이유: 사용자 요청. 채널마다 주제·방식·올릴 계정이 다르다. 채널 ID 를 화면에서 고칠 수 있어야 채널을 추가하기 쉽다.
- 검토한 대안: 채널 ID 도 GitHub 변수로(채널마다 변수를 하나씩 더 만들어야 함), 토큰을 DB 에 저장(비밀값이 DB 에 남음).
- 영향: `channels` 테이블, `episodes.channel`(기존 에피소드는 라쿤씨). GitHub 변수 `YOUTUBE_CHANNEL_ID` 는 더 쓰지 않는다.
- 다음 단계로 합의한 것(각각 별도 PR):
  1. 영상 길이 20~59초 가변(라쿤씨 기본 30초), 60초는 대본·내레이션·합성 세 곳에서 막는다.
  2. 라쿤씨 추천: **이틀에 한 번** 카테고리(화장품 성분 · 피부건강 꿀팁 · 피부 과학) 하나씩 3개 **기획안**(제목·훅·목차·길이)만 만들고,
     고른 기획안만 근거 조사와 대본을 진행한다. 저장·폐기. 프롬프트는 화면에서 고친다. 자동 실행은 기본 꺼짐(켜는 것이 비용 승인).
  3. 업로드 큐: 날짜·시각은 사용자가 정한다(기본은 올리지 않음). 정하면 비공개 + 예약 공개로 올려 두고, 바꾸면 예약 시각도 바꾼다.
  4. 새새 열매(편집형): 사진 소스·사진 움직임(켄 번스), 새 소재 풀 매일 수집, 매일 스토리 후보 3개. 새 관련 소재만.
  - 라쿤씨는 채널 이름일 뿐 영상에 캐릭터로 나오지 않는다. 월 크레딧 예산은 한 달 써 본 뒤 정한다.

## 2026-11-18 에피소드를 만드는 길 두 가지, 영상 소스는 에피소드로

- 결정: 새 에피소드에서 만드는 길을 고른다.
  - **주제로 만들기**(기존): 주제·목차 → 대본 → 내레이션 → 장면 생성(AI) → 영상 → 업로드
  - **영상 먼저 찾기**: 주제·연관 단어 → 무료 영상 찾기 → 장면 4개를 직접 골라 순서 지정 + 컨셉·목차 → 대본(고른 클립 설명을 함께 넘김)
    → 내레이션 → 영상 → 업로드. 고른 4개만 채택하고, 대본을 승인하면 그 클립으로 장면을 채운다(장면 생성 없음, 크레딧 0)
  - 상단 "영상 소스" 메뉴는 "클립 보관함"(찾은 영상 둘러보기·채택·매일 자동 수집 관리)으로 남기고, 영상 찾기는 에피소드에서 한다
- 이유: 사용자 요청. 클립에 맞춰 대본을 써야 화면과 내레이션이 맞고, 장면 크레딧이 들지 않는다.
- 검토한 대안: Claude 가 장면마다 클립을 골라 연결(손이 덜 가지만 화면 구성을 사람이 정하지 못함), 대본을 먼저 쓰고 클립은 직접 배치(지금의 장면 채우기).
- 영향: `episodes.route`(기존 에피소드는 ai), `episode_clips`(장면별 고른 클립). 대본 형식(장면 4개)은 그대로.
